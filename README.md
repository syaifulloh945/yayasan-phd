# Website Yayasan Pemuda Harapan Dunia

Website resmi Yayasan Pemuda Harapan Dunia: cerdas, berkarakter, berakhlak mulia.

Satu file `index.html` (HTML, CSS, dan JavaScript jadi satu), tanpa proses build.

## Mengubah data
- Nomor WhatsApp: cari `var WA =` di bagian `<script>` paling bawah (format `62...`).
- Rekening, alamat, dan teks lain: edit langsung di `index.html`.
